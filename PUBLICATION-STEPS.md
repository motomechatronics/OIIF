# Publication steps (in order)

1. Founding author and permission to release the materials: confirmed by the author.
2. CC BY 4.0 licence: approved by the author; public notices updated.
3. Check and approve all drafts, particularly the origin statement and governance.
4. Create a **public GitHub repository** and upload the approved files.
5. Register on **Zenodo** and connect the GitHub account.
6. From Zenodo > GitHub, sync repositories and **enable this repository**.
7. Only now create GitHub release **v1.0.0** on the approved commit.
8. Wait for Zenodo archiving. Confirm that the DOI record names the founding author and points to the intended release.
9. Record the DOI and actual publication date in a later commit (not in a way that rewrites the original release).
10. Publish a LinkedIn announcement referring to the DOI and GitHub repository.

Note: Zenodo's GitHub integration predominantly uses software-deposit handling. Because OIIF is a *textual methodological proposal*, consider also a separate manual Zenodo **publication** record if academic-document categorization is important; avoid creating two confusing competing founding DOIs.
